# write-project-report

## Цель

Итоговый отчёт по этапу работ в проекте.

## Когда использовать

Завершение задачи, milestone, handoff разработчику.

## Шаги

1. Собрать: что создано/изменено, файлы, команды.
2. Добавить запись в `docs/PROJECT_LOG.md` (дата UTC).
3. При архитектурных решениях — `docs/DECISIONS.md`.
4. Краткий summary пользователю: health URL, admin URL, next steps.

## Шаблон PROJECT_LOG

```
## YYYY-MM-DD HH:MM UTC
- **Что изменено:**
- **Файлы:**
- **Команды:**
- **Результат:**
- **Ошибки:**
- **Следующий шаг:**
```

## Проверки

- Нет секретов в отчёте
- Ссылки на docs актуальны
