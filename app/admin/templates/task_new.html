О странице

Форма создаёт одну scraping-задачу по указанному URL — точка входа в pipeline, если адрес страницы уже известен.

Что делать

  • Вставьте URL статьи и нажмите «Создать задачу».
  • После создания откройте карточку задачи, затем документ и при необходимости редактуру.
  • Тип парсера можно оставить generic_article, если для домена нет специального парсера.
  • Для массового добавления URL используйте ручной импорт.
